# RamayanaVerse

RamayanaVerse is an interactive website dedicated to the epic Ramayana.

## Features

- Journey Timeline
- Character Encyclopedia
- Seven Kandas
- Character Search
- Interactive Navigation
- Responsive Design

## Main Characters

- Lord Rama
- Sita
- Hanuman
- Lakshmana
- Bharata
- Ravana
- Vibhishana
- Dasharatha
- Sugriva

## Built With

- Next.js
- React
- Tailwind CSS
